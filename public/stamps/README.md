# スタンプ画像

本番のスタンプイラスト（5ストリート × 2種類 = 10枚）を配置済み。
差し替える場合は同じファイル名で置き換えるだけで反映されます。

| ファイル | ストリート | 絵柄 |
| --- | --- | --- |
| `street-01-a.jpg` / `street-01-b.jpg` | 環境 | 緑のキャラと木 / 地球のネコとめばえ |
| `street-02-a.jpg` / `street-02-b.jpg` | 国際 | 青緑のキャラと旗 / 地球のまほうつかい |
| `street-03-a.jpg` / `street-03-b.jpg` | 福祉 | ピンクのキャラと車いす / 手をつなぐふたり |
| `street-04-a.jpg` / `street-04-b.jpg` | 子育て | 紫のキャラとにじ / 親子の魔女 |
| `street-05-a.jpg` / `street-05-b.jpg` | 文化・アート | オレンジのキャラとパレット / おばけダンス |

いずれも 400×400 のJPEG。円形に切り抜いて表示されるため、絵柄は中央寄りにしてあります。

## 新しく差し替えるときの手順

## 手順

1. 画像をこのフォルダに置く。ファイル名は以下の対応で付けると分かりやすい:

   | ファイル名 | ストリート | 仮デザイン |
   | --- | --- | --- |
   | `street-01-a.png` / `street-01-b.png` | 環境 | 🎃 かぼちゃ / 🌰 どんぐり |
   | `street-02-a.png` / `street-02-b.png` | 国際 | 🦇 こうもり / 🧙 まじょ |
   | `street-03-a.png` / `street-03-b.png` | 福祉 | 🍬 キャンディ / 👻 おばけ |
   | `street-04-a.png` / `street-04-b.png` | 子育て | 🧁 カップケーキ / 🍭 ロリポップ |
   | `street-05-a.png` / `street-05-b.png` | 文化・アート | 🎭 かめん / 🌙 おつきさま |

2. `src/data/streets.ts` の各デザインに `image` を追加する:

   ```ts
   { id: "a", name: "かぼちゃ", nameEn: "Pumpkin", emoji: "🎃", color: "#ea580c",
     image: "/stamps/street-01-a.png" },
   ```

   `image` を設定したデザインは絵文字の代わりに画像で表示されます。
   設定していないものは絵文字のままなので、10枚を一度に揃える必要はありません。

## 画像の条件

- **正方形**を推奨（円形に切り抜いて表示されます）
- 400×400px 程度あれば十分（最大でも 160px 相当で表示）
- PNG・JPG・SVG が使えます。背景を透過させる場合は、`color` に設定した色が背景として見えます
- 画像の縁は円形にトリミングされるため、絵柄は中央寄りに配置してください
